allowed-tools:

garden 명령은 Bash 도구에서 실행한다.

요청: $ARGUMENTS

- 기본: `{{garden}} map`
- 폴더를 나눈 이유까지: `{{garden}} map --why`
- 무엇부터 할지: `{{garden}} map --order`
- 그래프: `{{garden}} map --mermaid` (mermaid 코드 블록으로 감싸서 보여 준다)

결과는 고치지 말고 그대로 보여 준다. 그다음 짧게 읽어 준다.

- 각 줄: `폴더/  목표  #중요도(형제 중, 1이 가장 중요)  목적   ← 먼저 필요한 폴더`
- `⚠ 확인 필요`: 이 폴더가 필요로 하는 폴더의 개념이 바뀌었다
- `⚠ 목표 연결 없음`: serves가 비었거나 SEED에 없는 목표다
- `카드 없는 최상위 폴더`: 아직 목적이 적히지 않은 폴더다
